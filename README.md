💰 Smart Expense Tracker

A Smart Expense Tracker built using HTML, CSS, and JavaScript. This application helps users manage their daily income and expenses, calculate their remaining balance, and maintain a transaction history.

✨ Features

- Add income transactions
- Add expense transactions
- Enter transaction names and amounts
- Select transaction categories
- Choose transaction dates
- Calculate total income automatically
- Calculate total expenses automatically
- Display remaining balance
- View transaction history
- Delete transactions
- Save transaction data using Local Storage
- Responsive user interface

🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "expense-tracker.html" in your web browser.
4. Enter the transaction name.
5. Enter the amount.
6. Select Income or Expense.
7. Choose a category and date.
8. Click Add Transaction.

💡 How It Works

The application stores transaction details in the browser's Local Storage.

It automatically calculates:

- Total Income
- Total Expenses
- Remaining Balance

The balance is calculated using:

Remaining Balance = Total Income - Total Expenses

🎯 Project Objective

The objective of this project is to help users track their daily financial activities and understand their spending habits through a simple and user-friendly interface.
